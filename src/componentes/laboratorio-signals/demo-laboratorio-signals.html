    📚 Referencia Rápida Mita-DOM v2.7

    Cada tarjeta incluye su sintaxis real y un acceso directo para probarla en el Sandbox de arriba.

    • crearEstadoLocal(valor)

      Estado privado de un solo Web Component (contadores, filtros, pestañas).

      const ui = crearEstadoLocal({ clicks: 0 });
ui.patch({ clicks: ui.get().clicks + 1 });

    • crearEstadoCompartido(...)

      Comparte datos entre 2+ componentes con persistirLocal, descripcion y reglas.

      crearEstadoCompartido('empleos:cfg', { habilitado: true }, { persistirLocal: true });

    • obtenerEstadoCompartido(nombre)

      Conecta cualquier componente hermano o hijo al mismo Signal sin props drilling.

      const cfg = obtenerEstadoCompartido('empleos:cfg');
cfg.patch({ habilitado: false });

    • renderCondicional({ ... })

      Monta o destruye nodos reales del DOM según una condición (sin display: none).

      this.mostrarSi({ estado: cfg, contenedor: el, cuando: (c) => c.habilitado, mostrar: () => '<form>...</form>' });

    • vincularTexto(sig, nodo, fmt)

      Actualiza únicamente textContent preservando el mismo TextNode (0 XSS).

      const stop = vincularTexto(ui, span, (e) => `Clicks: ${e.clicks}`);

    • crearEfecto(fn) + .derivar(fn)

      Auto-rastrea múltiples Signals con limpieza detener() y auditoría listarEstadosCompartidos().

      const total = items.derivar((l) => l.length);
const stop = crearEfecto(() => console.log(total.get()));

      <lab-tarjeta-reusable titulo="Empleos" variante="exito" texto-accion="Publicar"></lab-tarjeta-reusable>
